All explainers

The prompt and code behind these explainers

Everything here is what my AI assistant follows to turn a topic into one animated web page. The prompt first, then how the page is generated, then the code.

How a page gets made, in one line

Topic→Facts from primary sources→Outline of 12 to 18 steps→One scene per step (Python)→build.py→One HTML file→Screenshot every step→Publish

1. The prompt (the instructions the assistant follows)

# Explainer

The original prompt: "explain this hyper intuitively bottoms up with the most simple step by step animations so i really understand concretely", then "share a html".

## The bottom-up rule
- Start with the smallest working piece (a model on its own, a single tool).
- Add ONE idea per step.
- Open each step with the problem the last step left. Append "Next problem: ..." to the last beat via BRIDGE.
- Put the whole picture together near the end, then attacks or failure cases, cost, what is proven, what is not yet, and what each audience takes away.
- If two steps can swap places, it is a list, not a build. Reorder.

## Method
1. Gather facts from primary files only (docs, evidence, code). Mark preview features, made-up data and "my reading" items. Do not invent numbers. State measured figures with how they were measured.
2. Outline 12 to 18 steps, each answering one question.
3. Copy the kit: a new working folder, then copy the kit files into it. 
4. Write `scenes_<topic>.py`. Each scene function returns `dict(title, narr, say, aud, svg)`:
   - svg: built from engine.py helpers (T, TL, R, Gp, Ln, Box, Bub, Person, Key, Lock, Doc, Cap, Card, Tag). Viewbox is 960 wide by about 600 tall. Beats use `s=` (first beat shown) and `e=` (first beat hidden). Beat 0 is visible from the start.
   - narr: plain explanation, one per beat.
   - say: the words to speak, one per beat, 8 to 20 words. `len(say) == len(narr)` (build.py asserts).
   - aud: dict(exec=, sec=, ops=) one line each.
   - 
5. Edit CONFIG at the top of `build.py` (TITLE, BRAND, OUT, ORDER, BRIDGE, QS, INTRO_PARAS). Quiz: 6 to 8 questions, answers rotate automatically.
6. Build: `/usr/bin/python3 build.py` (Pillow and other libs live on the system Python).
7. Check: `./shot.sh "$PWD/<out>.html" <scene> <beat> /tmp/x.png` for the last beat of every step, then OPEN each image and look for overflow, overlap and clipped text. Exit 0 proves nothing visual. 
8. Fix, rebuild and send the finished HTML file.

## The Say box is a story, not a caption 
- Each step gets one small story told across its beats: a generic person or agent ("a customer", "a team", "an agent", never a named character), one want, one thing that goes wrong, one fix.
- The exam or product term arrives last, as the name for what just happened. The listener should be able to repeat it to someone else.
- End the step with one plain line: the answer to carry into the exam or the room.
- Few words. Lines still align one per beat, so each beat moves the story one step.

## Voice
- Humanizer rules: short plain sentences, "I" not "we", no em dashes, no emoji, no not-X-but-Y.
- Teach from zero. Plain word first, then the proper term. Never an unexplained acronym.
- In the file, "Say this" is first person. Flag which claims say "I built/tested" so the speaker can change them.
- Fictional data only in examples and labs.

2. How the screens are generated

  • Each step is a small Python function called a scene. It returns five things: a title, one plain explanation per beat, one line to speak per beat, a one-line note for each audience, and the drawing.
  • The drawing is an SVG built from a few helper functions: text, rectangles, groups, lines, boxes, speech bubbles, people, keys, locks, documents, cards and tags. The canvas is 960 wide by about 600 tall.
  • Each drawn item says on which beat it appears and on which beat it disappears. That is how the animation steps forward.
  • The build script loads every scene, checks that each beat has both an explanation and a line to speak, rotates the quiz answers, and pours everything into one HTML template as JSON.
  • The template holds the interface: a step menu, next and previous buttons, the red "Say this" panel with a script on/off switch, the audience panel and the quiz. No server and no libraries. One file works offline.
  • A screenshot script opens each step at its last beat in headless Chrome so I can look for clipped or overlapping text before it ships.

3. The build script

Source: kit/build.py

"""Generic explainer builder. Copy this kit to ~/work/<topic>/explainer-html/, then edit CONFIG and write scenes_*.py.
Run with: /usr/bin/python3 build.py
Each scenes module exposes SCENES = [fn, ...]; each fn returns dict(title, narr, say, aud, svg)."""
import sys, os, json, importlib
HERE = os.path.dirname(os.path.abspath(__file__))
sys.path.insert(0, HERE)
from engine import DEFS

# ---- CONFIG: edit these ----
TITLE = 'Example explainer'
BRAND = 'Example · fictional data'
OUT = 'explainer.html'
ORDER = [('example_scenes', 0), ('example_scenes', 1), ('example_scenes', 2), ('example_scenes', 3)]  # (module, index in SCENES)
BRIDGE = {}  # scene title -> "Next problem: ..." appended to the last beat of that step
# quiz: [cue, ask, [options], index of right answer, why]. rotate() moves the right answer around.
QS = [
 ['"Example question the room will ask?"', 'What do you say?', ['Wrong one', 'The right one', 'Another wrong one'], 1, 'Why the right one is right.'],
]
INTRO_PARAS = ['One or two plain sentences on what this is and who it is for.', 'Each step has a small animation, a plain explanation and a red box with the words to say.']
# ---- end CONFIG ----

def rotate(qs):
    out = []
    for i, (cue, ask, opts, ok, why) in enumerate(qs):
        k = [0, 2, 1][i % 3]
        opts2 = opts[k:] + opts[:k]
        out.append([cue, ask, opts2, (ok - k) % len(opts), why])
    return out

def collect():
    scenes = []
    for mod, k in ORDER:
        sc = importlib.import_module(mod).SCENES[k]()
        sc['svg'] = DEFS + sc['svg']
        br = BRIDGE.get(sc['title'])
        if br:
            sc['narr'][-1] += ' ' + br
            sc['say'][-1] += ' ' + br
        assert len(sc['say']) == len(sc['narr']), sc['title']
        scenes.append(sc)
    return scenes

if __name__ == '__main__':
    scenes = collect()
    paras = ''.join(f'<p>{p}</p>' for p in INTRO_PARAS)
    introhtml = '`<div class="card"><h2>' + TITLE + '</h2>' + paras + '<ol>${PY.map(s=>`<li>${s.title}</li>`).join(\'\')}</ol></div>`'
    intro = json.dumps({'kind': 'intro', 'title': TITLE, 'narr': ['Start']})
    tpl = open(f'{HERE}/template.html').read()
    out = (tpl.replace('__SCENES__', json.dumps(scenes, ensure_ascii=False)).replace('__INTRO__', intro)
              .replace('__QS__', json.dumps(rotate(QS), ensure_ascii=False)).replace('__INTROHTML__', introhtml)
              .replace('__TITLE__', TITLE).replace('__BRAND__', BRAND))
    open(f'{HERE}/{OUT}', 'w').write(out)
    print(len(scenes), 'scenes,', sum(len(s['narr']) for s in scenes), 'beats,', round(len(out) / 1024), 'KB')

4. The drawing helpers

Source: kit/engine.py

"""Tiny DSL for the step-by-step Domain 1 explainer. Everything is inline SVG with data-* beat attributes."""
INK, GREY, RED, SOFT = '#111111', '#6b7280', '#d71f26', '#eceef1'

def A(**k):
    return ''.join(f' data-{key}="{v}"' for key, v in k.items() if v is not None)

def esc(t):
    return t.replace('&', '&amp;').replace('<', '&lt;').replace('>', '&gt;')

def T(x, y, t, size=30, fill=INK, anchor='start', w=400, **k):
    return f'<text x="{x}" y="{y}" font-size="{size}" fill="{fill}" text-anchor="{anchor}" font-weight="{w}"{A(**k)}>{esc(t)}</text>'

def TL(x, y, lines, size=28, fill=INK, anchor='start', w=400, lh=None, **k):
    lh = lh or size * 1.28
    inner = ''.join(f'<tspan x="{x}" dy="{0 if i == 0 else lh}">{esc(l)}</tspan>' for i, l in enumerate(lines))
    return f'<text x="{x}" y="{y}" font-size="{size}" fill="{fill}" text-anchor="{anchor}" font-weight="{w}"{A(**k)}>{inner}</text>'

def R(x, y, w, h, fill='#fff', stroke=INK, sw=4, rx=14, dash=None, **k):
    d = f' stroke-dasharray="{dash}"' if dash else ''
    return f'<rect x="{x}" y="{y}" width="{w}" height="{h}" rx="{rx}" fill="{fill}" stroke="{stroke}" stroke-width="{sw}"{d}{A(**k)}/>'

def Gp(inner, **k):
    return f'<g{A(**k)}>{inner}</g>'

def Ln(x1, y1, x2, y2, stroke=INK, sw=4, arrow=False, dash=None, **k):
    d = f' stroke-dasharray="{dash}"' if dash else ''
    m = (' marker-end="url(#%s)"' % {RED: 'ahr', GREY: 'ahg'}.get(stroke, 'ah')) if arrow else ''
    return f'<path d="M{x1} {y1} L{x2} {y2}" stroke="{stroke}" stroke-width="{sw}" fill="none"{d}{m}{A(**k)}/>'

def Box(x, y, w, h, label, size=30, sub=None, fill='#fff', stroke=INK, sw=4, dash=None, rx=14, **k):
    cx = x + w / 2
    if sub:
        body = T(cx, y + h / 2 - 2, label, size, INK, 'middle', 700) + T(cx, y + h / 2 + 28, sub, 22, GREY, 'middle', 400)
    else:
        body = T(cx, y + h / 2 + size * 0.35, label, size, INK, 'middle', 700)
    return Gp(R(x, y, w, h, fill, stroke, sw, rx, dash) + body, **k)

def wid(t, size, pad=40):
    return int(len(t) * size * 0.56 + pad)

def Bub(x, y, t, size=26, fill='#fff', stroke=INK, w=None, **k):
    w = w or wid(t, size)
    return Gp(R(x, y, w, size + 30, fill, stroke, 3, 18) + T(x + w / 2, y + size + 8, t, size, INK, 'middle', 400), **k)

def Person(x, y, label='You', **k):
    return Gp(f'<circle cx="{x}" cy="{y-30}" r="22" fill="#fff" stroke="{INK}" stroke-width="4"/>'
              f'<path d="M{x-36} {y+44} a36 36 0 0 1 72 0 z" fill="#fff" stroke="{INK}" stroke-width="4"/>'
              + T(x, y + 84, label, 26, INK, 'middle', 700), **k)

def Key(x, y, color=RED, s=1.0, **k):
    return Gp(f'<g transform="translate({x},{y}) scale({s})"><circle cx="10" cy="15" r="9" fill="none" stroke="{color}" stroke-width="4.5"/>'
              f'<path d="M19 15 H46 M38 15 V25 M44 15 V23" stroke="{color}" stroke-width="4.5" fill="none"/></g>', **k)

def Lock(x, y, color=INK, s=1.0, **k):
    return Gp(f'<g transform="translate({x},{y}) scale({s})"><rect x="0" y="14" width="30" height="22" rx="4" fill="{color}"/>'
              f'<path d="M5 14 V9 a10 10 0 0 1 20 0 V14" fill="none" stroke="{color}" stroke-width="4.5"/></g>', **k)

def Doc(x, y, w=70, h=90, **k):
    return Gp(R(x, y, w, h, '#fff', INK, 3, 6) + ''.join(f'<path d="M{x+12} {y+22+i*20} H{x+w-12}" stroke="{GREY}" stroke-width="3"/>' for i in range(3)), **k)

DEFS = '<defs>' + ''.join(f'<marker id="{i}" markerUnits="userSpaceOnUse" markerWidth="18" markerHeight="18" refX="15" refY="9" orient="auto"><path d="M0 0 L16 9 L0 18 Z" fill="{c}"/></marker>' for i, c in (('ah', INK), ('ahr', RED), ('ahg', GREY))) + '</defs>'

def Cap(t, s=None, e=None, y=560, col=INK, size=26):
    return T(480, y, t, size, col, 'middle', 700, s=s, e=e)

def Card(x, y, w, h, title, sub=None, hot=False, dash=None, **k):
    body = R(x, y, w, h, '#fff', RED if hot else INK, 4, 14, dash)
    if sub:
        body += T(x + w / 2, y + h / 2 - 2, title, 26, RED if hot else INK, 'middle', 700) + T(x + w / 2, y + h / 2 + 28, sub, 20, GREY, 'middle')
    else:
        body += T(x + w / 2, y + h / 2 + 9, title, 26, RED if hot else INK, 'middle', 700)
    return Gp(body, **k)

def Tag(x, y, t, size=20, **k):
    w = int(len(t) * size * 0.6 + 24)
    return Gp(R(x, y, w, size + 14, '#fff', RED, 2, 8) + T(x + w / 2, y + size + 1, t, size, RED, 'middle', 700), **k)
